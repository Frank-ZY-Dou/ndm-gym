# Simulator

The simulator modules (`ndm_gym.sim.rigid.isaaclab_mjwarp`, `hdmi_sim`, `muscle_sim`) need Isaac Lab 3, Newton and
MuJoCo-Warp, `hand_sim` MuJoCo-Warp alone ([Installation](../installation.md)). Without them, they and the commands that run them raise
`SimulatorNotInstalled`.

::: ndm_gym.sim

::: ndm_gym.sim.launcher

RoboKit's simulator subclasses need RoboKit and MuJoCo Warp, imported when they are built ([task](../tasks/robokit.md)).
